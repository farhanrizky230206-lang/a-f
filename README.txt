CARA MEMBUKA
1. Buka index.html di Chrome/Safari untuk melihat undangan.
2. Tekan "Buka Undangan" — pemutar Spotify akan muncul.
3. Tekan Play pada player Spotify. Lagu penuh tidak bisa dipaksakan autoplay, dan pengunjung mungkin perlu login Spotify / membuka aplikasi untuk mendengar versi penuh. Pada beberapa kondisi, pemutar hanya menampilkan cuplikan.
4. Klik simbol ♫ di kanan bawah untuk membuka atau menutup pemutar Spotify. Ada juga tombol di bagian Our Special Song.

PENGATURAN TERAKHIR SEBELUM DISEBARKAN
- RSVP: Di index.html cari 'whatsappNumber: ''' lalu isi nomor penerima, contoh 6281234567890. Jika kosong, tombol RSVP menampilkan pesan agar diisi.
- Galeri: Gambar masih contoh, ganti URL gambar dengan foto Farhan dan Amel.
- Peta: Tombol membuka pencarian alamat di Google Maps, bukan lokasi pin yang sudah diverifikasi.

DEPLOY KE VERCEL
1. Ekstrak zip, upload index.html dan README.txt ke root repository GitHub.
2. Hubungkan repository ke Vercel, pilih framework Other dan deploy.
3. Tautan untuk tamu tertentu: https://alamat-situs.vercel.app/?to=Nama%20Tamu

PENTING: Tidak perlu menambahkan music.mp3 lagi. Musik disediakan lewat Spotify Embed resmi.
